# 歌词转PPT工具 使用说明

## 📝 基本使用（3步完成）

### 1. 输入歌词
在左边框框里面输入或粘贴歌词

### 2. 调整设置（可选）
- **每页几行**：建议 2-4 行
- **字体大小**：建议 48
- **字体颜色**：点击按钮选颜色

### 3. 生成PPT
点击 **"生成PPT"** 按钮，选择保存位置，完成！

---

## 🎨 常用功能

### 添加拼音
勾选 ☑️ **"启用拼音"**

**效果：**
```
我曾经跨过山和大海
wo ceng jing kua guo shan he da hai
```

---

### 更换背景图
点击 **"选择背景图"** → 选择一张图片

**支持格式：** JPG, PNG, GIF, BMP

---

### 调整歌词位置
**垂直位置** 数字越小越靠上
- 100 = 靠上（推荐）
- 200 = 居中
- 300 = 靠下

---

## 🎵 特殊功能

### 段落标记

在歌词前面加字母标记：

```
V 第一段歌词...     (主歌)
C 副歌部分...       (副歌)
B 桥段部分...       (桥段)
```

**注意：** 字母后面要有**空格**

**效果：** 标记会显示在PPT底部

---

### 手动分页

在想要分页的那一行**末尾**加上 `/`

**例子：**
```
我曾经像你像他/
像那野草野花
```

会分成两页。

---

## 💾 保存和加载歌词

### 保存歌词
1. 输入歌词
2. 点击 **"保存歌词"**
3. 输入歌名

### 加载歌词
1. 点击 **"加载歌词"**
2. 双击想要的歌名
3. 歌词自动填入

### 搜索歌曲
在搜索框输入歌名，自动筛选

### 按字母查找
点击 A-Z 按钮，只显示该字母开头的歌

---

## ☁️ 在线功能（可选）

### 为什么用在线？
✅ 多台电脑共享歌词
✅ 不怕电脑坏掉丢失
✅ 所有人都能看到

### 怎么开启？

#### 第一步：获取密钥
1. 登录 **GitHub.com**
2. 右上角头像 → **Settings**
3. **Developer settings** → **Personal access tokens** → **Tokens (classic)**
4. **Generate new token (classic)**
5. 填写：
   - Note: `歌词库`
   - Expiration: `No expiration`
   - 勾选: ☑️ `gist`
6. 点 **Generate token**
7. **复制**显示的密钥（`ghp_xxxxx...`）

#### 第二步：在程序里设置
（需要技术人员帮忙设置一次，之后就能一直用）

## ❓ 常见问题

**Q: 拼音不对怎么办？**
A: 可以不勾选"启用拼音"，自己手动输入拼音

**Q: 每页歌词太多/太少？**
A: 调整"每张幻灯片行数"的数字
- 数字越大 = 每页越多行
- 数字越小 = 每页越少行

**Q: 字太小/太大？**
A: 调整"字体大小"
- 不启用拼音：50-70
- 启用拼音：40-50

**Q: 背景图变形了？**
A: 正常的，图片会自动缩放填满屏幕
- 建议用横版图片

**Q: 找不到保存的歌词？**
A: 
- 用搜索框搜索歌名
- 或点击字母按钮查找

**Q: 预览和生成的不一样？**
A: 应该是一样的，如果不一样请联系技术支持

## 💡 小技巧

### 技巧 1：批量制作
把所有歌词都先保存好，然后一首一首加载生成

### 技巧 2：固定设置
调好字体、颜色、背景后，设置会保留，不用每次重新设置

### 技巧 3：先预览再生成
右边能看到预览，满意了再点"生成PPT"

### 技巧 4：标记要统一
建议统一用法：
- V = 主歌
- C = 副歌  
- B = 桥段

### 技巧 5：手动分页
如果自动分页不满意，在想断开的地方加 `/`
