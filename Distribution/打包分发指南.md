# 打包可执行JAR文件指南

## 方法1：使用Maven打包（推荐）

### 步骤1：构建JAR文件

在项目目录下运行：

```bash
mvn clean package
```

### 步骤2：找到生成的JAR文件

构建成功后，在 `target/` 目录下会生成：

```
target/
├── lyrics-to-slides-1.0-SNAPSHOT.jar                          (较小，不包含依赖)
└── lyrics-to-slides-1.0-SNAPSHOT-jar-with-dependencies.jar    (完整版，包含所有依赖)
```

**重要**：分享给别人使用 `lyrics-to-slides-1.0-SNAPSHOT-jar-with-dependencies.jar` 这个文件！

### 步骤3：重命名JAR文件（可选）

为了方便使用，可以重命名：

```bash
# Windows
copy target\lyrics-to-slides-1.0-SNAPSHOT-jar-with-dependencies.jar 歌词转PPT.jar

# Mac/Linux
cp target/lyrics-to-slides-1.0-SNAPSHOT-jar-with-dependencies.jar 歌词转PPT.jar
```

### 步骤4：测试JAR文件

```bash
java -jar 歌词转PPT.jar
```

## 🎨 创建Windows双击运行脚本（可选）

如果用户不会用命令行，可以创建一个启动脚本：

### 创建 `启动歌词转PPT.bat` 文件：

```batch
@echo off
title 歌词转PPT工具
echo 正在启动歌词转PPT工具...
echo.

REM 检查Java
java -version >nul 2>&1
if %errorlevel% neq 0 (
    echo ===============================================
    echo 错误：未检测到Java！
    echo 请先安装Java：https://adoptium.net/
    echo ===============================================
    pause
    exit /b 1
)

REM 运行程序
java -jar 歌词转PPT.jar

if %errorlevel% neq 0 (
    echo.
    echo ===============================================
    echo 程序运行出错！
    echo 请确保"歌词转PPT.jar"文件在同一目录下
    echo ===============================================
    pause
)
```

### 创建 Mac/Linux 启动脚本 `启动歌词转PPT.sh`：

```bash
#!/bin/bash

echo "正在启动歌词转PPT工具..."
echo

# 检查Java
if ! command -v java &> /dev/null; then
    echo "==============================================="
    echo "错误：未检测到Java！"
    echo "Mac用户请运行：brew install openjdk"
    echo "或访问：https://adoptium.net/"
    echo "==============================================="
    exit 1
fi

# 运行程序
java -jar 歌词转PPT.jar
```

记得给脚本执行权限：
```bash
chmod +x 启动歌词转PPT.sh
```
