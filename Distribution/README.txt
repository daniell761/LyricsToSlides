# 歌词转PPT工具

## 📖 简介

这是一个简单易用的工具，可以快速将歌词转换成精美的PowerPoint演示文稿。

## ✨ 特点

- 🎨 深色现代主题，专业美观
- 📱 简洁的图形界面，操作简单
- ⚡ 快速生成，一键完成
- 🔧 可自定义每页行数
- 📄 自动添加标题页和结束页
- 💯 完全免费，开源

## 📦 文件说明

- **歌词转PPT.jar** - 主程序文件
- **启动歌词转PPT.bat** - Windows启动脚本
- **启动歌词转PPT.sh** - Mac/Linux启动脚本
- **使用说明.txt** - 详细使用指南
- **示例歌词.txt** - 歌词格式示例

## 🚀 快速开始

### 1. 确保已安装Java

检查方法：打开命令提示符/终端，输入：
```
java -version
```

如果显示版本信息（需要Java 8或更高），说明已安装。

如果没有安装，请访问：https://adoptium.net/

### 2. 运行程序

**Windows用户：**
- 方法1：双击 `歌词转PPT.jar`
- 方法2：双击 `启动歌词转PPT.bat`（推荐，会检查环境）

**Mac/Linux用户：**
- 方法1：双击 `歌词转PPT.jar`
- 方法2：运行 `./启动歌词转PPT.sh`

### 3. 使用步骤

1. 在"PPT标题"框输入标题（例如：平凡之路）
2. 设置"每张幻灯片行数"（建议4行）
3. 在文本框中粘贴或输入歌词
4. 点击"生成PPT"按钮
5. 选择保存位置和文件名
6. 完成！可选择立即打开查看

## 💡 使用技巧

- **歌词格式**：每行一句，程序会自动处理空行
- **行数设置**：
  - 短歌词：6-8行/页
  - 普通歌词：4行/页（推荐）
  - 长歌词：2-3行/页
- **标题**：可以输入歌名、艺人等信息

## 📋 示例

参考 `示例歌词.txt` 文件查看正确的歌词格式。

## ❓ 常见问题

**Q: 双击JAR文件没反应？**
A: 使用启动脚本（.bat或.sh），它会检查Java环境并提示错误。

**Q: 提示需要Java？**
A: 访问 https://adoptium.net/ 下载安装Java。

**Q: 生成的PPT打不开？**
A: 确保保存路径正确，没有特殊字符，且有写入权限。

**Q: 想修改PPT样式？**
A: 当前版本不支持在界面修改，需要修改源代码。
